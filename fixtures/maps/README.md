# Generated maps

Adventure-lane fixtures (`lanes.toml`): `.h3m` files our own code generates, committed once, so
that tests, golden replays and benchmarks play a real map file without the original game's maps
(those stay local, `docs/formats/h3m.md`; the user dropped hand-made editor maps, E08 2026-10-11).

Each file is laid out by `crates/h3-map/src/tests/fixtures.rs` from a plan built with a fixed
generator, written gzip-compressed as the game stores maps; the rewards map (E08 T64a) is written
by `h3_map::writer` instead, object by object, in `crates/h3-map/src/tests/rewards_map.rs`, and so
are decision 133's two full maps (E08 T64b) in `crates/h3-map/src/tests/full_maps.rs`, the sea map (E08 T75a) in `crates/h3-map/src/tests/sea_map.rs`, the sea XL (E08 T75b) in `crates/h3-map/src/tests/sea_xl_map.rs` the economy map (E08 T86a) in `crates/h3-map/src/tests/economy_map.rs` the economy XL (E08 T86b2) in `crates/h3-map/src/tests/economy_xl_map.rs`, the dwellings map (E08 T96a) in `crates/h3-map/src/tests/dwellings_map.rs` the gates XL (E08 T104) in `crates/h3-map/src/tests/gates_map.rs` and the teleporters map (E08 T106a) in `crates/h3-map/src/tests/teleporters_map.rs`. The typed objects (E08 T16a) are
drawn after the terrain and the blockers, so those stayed as they were; each object's tiles are
free land off the roads (a guard's or a gate's on them), its visitable tile keeps two free
neighbours it is reached from not from above, and none covers a hero or another object. Increment
3's (E08 T20b3b2) are drawn after those, so those stayed as they were too: the property plans'
monsters, guarded piles and special grounds (`play.rs`), no monster within two tiles of a hero. That
file's test reads each committed map and checks that it is still its plan's map and imports. A
change of a committed map changes its content hash and so invalidates every replay that names it
(ADV-Q2): regenerate only on purpose, with `H3_WRITE_FIXTURES=1 cargo test -p h3-map --lib
tests::fixtures` (the rewards map: `tests::rewards_map`; the full maps: `tests::full_maps`; the sea map: `tests::sea_map`; the sea XL: `tests::sea_xl_map`; the economy map: `tests::economy_map`; the economy XL: `tests::economy_xl_map`; the gates XL: `tests::gates_map`; the teleporters map: `tests::teleporters_map`), and
say why in the commit message. E08 T72 rewrote the duel, the XL and the army maps once: their
blocker templates' class moved from 124, which the import now types as a hole, to 118 (a crater, still a
blocker), so each imports to the same static map as before; their replays were re-recorded with
their commands unchanged.
