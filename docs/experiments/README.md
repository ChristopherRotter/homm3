# Experiments in the original game

Staged battles that the user plays in the original game to settle disputed rules (OPEN-QUESTIONS
Q28; E04a T2). The engine writes the maps; agents never write into the installation. Results hold
for the user's version only: **SoD, Complete 4.0**; a rule settled here is `observation`-sourced
with that version.

## Flow

1. An agent writes a map with `h3_formats::h3m` (format notes: `docs/formats/h3m.md`) into the
   gitignored folder `experiments/out/` of the repo.
2. The user copies it into the game's `Maps` folder, starts it under *New Game → Single Scenario*,
   follows the procedure and reports what the record section asks for.
3. The agent records the result here and in the rule catalog (the rule's source becomes
   `observation`), or in OPEN-QUESTIONS if the result is unclear.

## Smoke map (`E04a-smoke.h3m`)

Generated by `cargo run -p h3-formats --example smoke_map -- original-data/extracted/H3bitmap/Objects.txt experiments/out/E04a-smoke.h3m`.
36 × 36 grass. Red (you): *Smoke Red* (Orrin, Knight) with 20 Archers and 10 Pikemen, Advanced
Archery, Basic Armorer, Centaur's Axe (right hand), a Ballista, primary skills 5/4/1/1. Blue
(computer): *Smoke Blue* (Crag Hack, Barbarian) right next to Red, with 30 Goblins and 10 Wolf
Riders, Basic Offense, primary skills 3/3/1/1. Three tiles south of Red: 10 Pikemen (savage, never
flee).

**Procedure**

1. Copy `experiments/out/E04a-smoke.h3m` into `D:\Heroes3\HoMM 3 Complete\Maps`.
2. Start it as a single scenario (Red, human). Does it appear in the list and load?
3. Open Red's hero screen: name, army, skills, artifacts (axe, Ballista), attack 7 (5 + 2),
   defense 4?
4. Attack Blue's hero. Does the battle start with Red's Ballista and the expected armies on both
   sides?
5. Optional: attack the Pikemen.

**Record:** "loads / does not load (message)", anything on the hero screen that differs from the
list above, anything odd in the battle.
