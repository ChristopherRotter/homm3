## Goal

A game played to its end as the original plays it: the map's alliances, the players eliminated and the game over by the standard rules, the scenario's special victory and loss conditions, the won scenario's score, and the setup's starting bonus and handicap. Each built as E08's and E09's increments are, on the shipped maps, so that the server lane can end and remove players in a hosted game, the AI lane's adventure env (E13) gets a terminal, and the game shell (E27) and the map client (E24) show the original's end screens and messages from the engine's reports instead of their stubs.

## Risks

- Elimination touches every system that iterates players (the day, the week, the turn order, the views, the server's seats): a defeated player must leave each without a stale reference.
- The conditions name objects by position in the file; the game's ids must survive captures, removals and an object that is replaced (a town's capture, a monster's defeat).
- The original's oddities (the flag's rewrite, the defeat-a-hero counting) may need quirk classifications with real gameplay impact: asked at each survey's checkpoint.
