# Adventure lane — what exists

The code map of the adventure lane, moved out of its HANDOFF's "Current state" on 2026-10-24 (verbatim; the HANDOFF keeps the position, the next step, the versions and the ids). Read the entry for the area your task touches: crates and modules by task (`T<n>`), the rule ids they carry (`ADV-*`, `GAM-*`, `HER-*`), and the versions they bump. Add a line here when a task builds a new area; the task's full record goes to `docs/epics/E08-log.md`.

- **Map reader and import** (`h3-map`): `read`/`parse` into `model::RawMap`; `import` into `h3_game::GameSetup`, `import_map` its static layer (`MAP_IMPORT_VERSION` 15, `docs/formats/h3m.md` "Import"; since T54 the players' human flags, the objects' scenery, a placed hero's sex; since T61b the banned spells and artifacts; since T72 the boats, the sea's objects, `HeroOnWater`; since T83a increment 9's classes, owners (`ObjectOwner`), abandoned mines' sets (`MineResources`), `OwnedOnWater`, the timed events). Every shipped map's static layer imports and validates; of the 160 shipped maps 8 import whole (T61b's census), the rest are typed `Unsupported`. `verify --with-original-data` runs `crates/h3-map/examples/original_data.rs` on the shipped maps.
